# Morph Hide n Seek

Minecraft Java **26.3 / Fabric**，当前版本 **0.4.4**。

## 玩法

一群玩家进入大厅，选择动物并准备。开局分配 **1–2 名猎人**，其余都是动物：2–5 人时 1 名猎人，6 人及以上 2 名猎人。角色偏好会参与分配。

动物先藏 30 秒，混入地图上的普通动物群；然后猎人进场，用铁剑追杀动物玩家。**血量归零就淘汰，进入观战。** UI 显示谁被谁淘汰，以及还有多少动物存活。

默认追捕 5 分钟。动物全部被淘汰，猎人胜；时间结束还有动物活着，动物胜，然后返回大厅。

没有计分、误伤惩罚、主动技能、追踪或缩圈。普通动物可以正常被杀死。

## 安装

- Minecraft 26.3，Java 25，Fabric Loader 0.20.1。
- 把 `build/libs/morph-hide-and-seek-0.4.4.jar` 放入游戏实例的 `mods` 文件夹，同时安装 Fabric API `0.165.0+26.3`。
- **替换旧版 JAR**，不要同时保留多个版本，不要安装 `-sources.jar`。
- 联机时，服务器与每位玩家都安装相同版本。服务器需要允许 PvP，才能使用原版玩家伤害。

## 进入游戏

主菜单左下角点击动物徽章，即可自动创建或打开专用存档 `WildVeil_Lobby`，直接进入大厅。首次打开需要等待世界加载。

已有世界中按 **M**，或使用 `/morph join` 进入。按键可在控制设置中修改。

大厅内点击 3D 动物模型选择化身。可以用下拉菜单筛选体型、选择阵营偏好，也可以搜索动物名。所有人准备后自动开局。只有一人时，点击「开始单人练习」即可探索地图与变身，练习没有猎人。正式对局至少需要 2 人，所有人点击「准备开始对局」后自动开局；界面会显示已准备人数。

## 淘汰与联机行为

- 玩家使用所选动物的最大生命值，HUD 原版爱心显示实际血量。
- 猎人攻击使用原版武器伤害、攻击蓄力、暴击、击退及受伤保护，不再按固定命中次数淘汰。
- 动物的显示实体受到攻击时，伤害由所属玩家承受；致命伤触发一次淘汰，自动进入旁观模式，不需要点复活。
- 猎人之间不能互相伤害，动物不能攻击其他玩家；大厅和藏匿阶段保护玩家。
- UI 右侧显示最近 4 条淘汰/退出记录，聊天显示完整通知。回合列表显示「已淘汰 / 未淘汰」，不显示分数。
- 动物退出或断线会离开本局并显示退出通知。所有猎人离线则动物获胜。
- 中途加入者在大厅等待下一局。场地边界固定，只负责防止离开场地。

## 动物与地图

可选择绵羊、小猪、奶牛、小鸡、兔子、狐狸。外观、碰撞体积、视角和生命值对应所选动物，不附带主动技能。移动按原版动物的普通步行参数换算，动物形态不会叠加玩家疾跑或疾跑跳跃加速；猎人仍正常行走、疾跑。参数来源和测试范围见 [动物移动速度](docs/MOVEMENT.md)。

大厅与场地位于独立维度 `morphhide:reserve`，每局随机重建树林、草垛、遗迹、道路和浅水。原世界建筑不受场地生成影响。

## 玩家数据与配置

加入前把玩家数据备份到世界目录的 `morphhide-backups/<UUID>.dat`。退出时恢复位置、物品、模式、属性等；断线后再次连接时尝试恢复。恢复失败时保留备份并记录日志。

`config/morphhide.json` 可以修改藏匿时间、追捕时间、倒计时、人数、普通动物数量和场地大小；重启生效。旧配置中的命中次数、终圈半径已不使用。

## 指令

`/morph join`、`/morph leave`、`/morph ready`、`/morph start`、`/morph stop`、`/morph practice`。

`start`、`stop`、`practice` 限大厅房主。技能指令和 R 技能按键已删除。

## 0.4.1 崩溃修复

修复进入大厅绘制 3D 动物时的 `Tried to access entity ID before ID assignment`。Minecraft 26.3 客户端中刚创建的实体 ID 为 0，而装备渲染状态提取即使处理空物品也会读取实体 ID。大厅模型没有网络生成包，因此改为通过统一工厂分配独立的负数 ID；预览模型不加入真实世界。

回归测试包含：复现原异常；使用原版绵羊和模拟客户端世界验证修复前后结果；模拟六个预览模型与重开界面，检查唯一 ID 及所有物品展示槽位的状态提取；处理不能创建的实体。这些回归测试覆盖日志中的实际异常路径；另通过客户端游戏测试实际渲染了六种模型并保存截图。

替换 0.4.0 JAR 后重新启动即可，沿用已有大厅存档。

## 0.4.2 游戏内测试与结算显示

新增可复跑的真实客户端与内置服务器测试。修复回合结算时 HUD 仍显示观战或追捕任务的问题，改为直接显示胜方和返回大厅倒计时。

## 0.4.3 动物步行速度

修复动物仍使用玩家移动输入和疾跑加速的问题。读取当前版本原版动物属性，结合普通游走倍率与 Mob 移动控制器的计算方式换算输入；动物形态禁用玩家疾跑及疾跑跳跃加速。退出变身后恢复玩家原有移动方式，不修改永久速度属性。

本次实测还修复了清理残留动物时修改实时实体集合导致迭代失效的问题；先收集再移除，并覆盖多实体同时清理回归。

## 0.4.4 名称与开局引导

显示名统一为 Morph Hide n Seek。单人大厅只提供直接开始练习的按钮，并明确正式对局至少 2 人；多人大厅显示准备人数与下一步操作。大厅 HUD 移除空计时器，练习 HUD 明确无猎人。旧专用存档目录保留以继续使用已有大厅。

新版大厅截图与验证见 [大厅引导](docs/LOBBY_UI.md)。
