# Morph Hide n Seek

Minecraft Java **26.3 / Fabric** 躲猫猫小游戏，当前版本 **0.13.0**。每个版本的改动见 [更新日志](CHANGELOG.md)。

动物玩家变成牛羊猪鸡兔狐，混进地图上的真动物里，还要去农田吃饱；猎人要把他们找出来。

## 一局流程

1. **大厅**：左键点大厅里的**牛**加入动物队，点**玩家模型**加入猎人队，不点就随机分配。按 **Shift+Y** 准备。
   - 只要有人准备，就开始 60 秒倒计时；准备的人越多，倒计时越短；全员准备立即开始。
   - 房主可以在控制墙上直接开始、进入练习场、设置猎人数和人数上限。
2. **倒计时 5 秒 + 生成地图**：动物队这时选动物，猎人出发前都可以按 **M** 更换。
3. **藏匿 5 秒**：动物传送到地图里，猎人留在大厅。
4. **追捕 3:30**：
   - 1:30 起进入诱饵阶段，猎人拿到小麦、胡萝卜和种子。真动物会跟着食物走，玩家变的不会。
   - 最后 1 分钟缩圈，边界缩到 12 格。动物在圈外会掉血，猎人会被挡回圈内。
5. **结算**：显示胜负、每人的阵营或动物、存活时间或被谁抓到，15 秒后回到大厅。

**猎人数**：自动模式下 1–5 人时 1 名猎人，6 人及以上 2 名；房主也可以固定为 1 或 2 名。正式对局至少 2 人，一个人可以去练习场（没有猎人，自由探索）。

## 动物

| 动物 | 要吃的食物 |
|---|---|
| 绵羊、奶牛 | 小麦 |
| 小猪、兔子 | 胡萝卜 |
| 小鸡 | 甜菜根 |
| 狐狸 | 甜浆果 |

- **任务**：去对应的农田，站在作物旁右键吃 **3 口**。每口要站着不动 3 秒，走开就会被打断。每吃一口都会发出这种动物的叫声，16 格内听得到。地图上有 8 块农田（每种 2 块），屏幕上方的任务栏会显示箭头和距离。
- **胜负**：不会提前结束。时间到时，没吃饱的动物饿死；只要有吃饱并活下来的动物，动物队就赢，否则猎人赢。
- **完全变身**：外观、碰撞箱、视角和生命值都和这种动物一样，回合中不会自然回血。第三人称、背包预览和其他玩家看到的都是动物模型，看不到人形、手和名字。
- **移动**：普通步行速度和原版动物一样，冲刺键相当于这种动物被食物引诱时的速度，没有冲刺跳。
- **伪装**：右键在普通草地上会低头吃草（绵羊用原版的吃草动画）。
- **队友**：动物队友的伪装带绿色描边和名字，只有动物队看得到。屏幕左侧有动物队名单，显示谁还活着、变成了什么、吃了几口。

## 猎人

- 拿**木剑**，不会损坏，用原版的伤害、蓄力、暴击和击退。打中动物模型或藏在里面的玩家都算。
- **打错惩罚**：打到真动物会被减速、失明、虚弱 3 秒。虚弱期间木剑没有伤害。
- 猎人只能看到动物队的名字和是否存活，看不到谁变成了什么。

## 地图上的真动物

- 每局随机生成主题地图（树林、草垛、遗迹、浅水、农田），默认放 54 只真动物，六种各占一份。
- 真动物被杀后，会在别处补一只同种的，尽量离猎人 16 格以外且不在视线内。所以把地图上的动物杀光也找不出玩家。
- 缩圈开始时，会选 12 只（每种 2 只）走进最终圈，其余留在原地。
- 真动物不会吃或踩坏农田。场地不会自然刷出其他生物（比如马），只有本局的动物。

## 安装

- 需要 Minecraft 26.3、Java 25、Fabric Loader 0.20.1 和 Fabric API `0.165.0+26.3`。
- 把 `build/libs/morph-hide-and-seek-<版本>.jar` 放进 `mods` 文件夹。**替换旧版本**，不要同时放多个版本，也不要放 `-sources.jar`。
- 联机时（包括局域网），房主和每位玩家都要装同一版本。

## 进入游戏

在主菜单左下角点击动物徽章，会自动创建或打开专用存档 `WildVeil_Lobby`，直接进入大厅。这个存档固定为晴天早上。局域网好友连进这个存档后会自动进入大厅；对局进行中才加入的人，在大厅等下一局。

在其他世界里，可以按 **M** 或用 `/morph join` 加入。按键可以在控制设置里修改。

## 指令

`/morph join`、`/morph leave`、`/morph ready`、`/morph start`、`/morph stop`、`/morph practice`。其中 `start`、`stop`、`practice` 只有房主能用。

## 玩家数据与配置

加入前，玩家数据会备份到世界目录下的 `morphhide-backups/<UUID>.dat`，离开时恢复位置、物品、游戏模式和属性。断线后重新连接也会尝试恢复。恢复失败时会保留备份并记录日志。

可以在 `config/morphhide.json` 里修改这些设置，重启后生效：

| 字段 | 默认值 | 含义 |
|---|---|---|
| `hideSeconds` | 5 | 藏匿时间（秒） |
| `huntSeconds` | 210 | 追捕时间（秒） |
| `lureSeconds` | 90 | 追捕开始后多少秒发放诱饵 |
| `shrinkSeconds` | 60 | 最后多少秒缩圈 |
| `shrinkFinalSize` | 12 | 缩圈最终宽度（格） |
| `shrinkHerd` | 12 | 缩圈时走进圈内的真动物数量 |
| `countdownSeconds` | 5 | 开局倒计时（秒） |
| `herdSize` | 54 | 每局真动物数量 |
| `maxPlayers` | 16 | 人数上限 |
| `arenaRadius` | 48 | 场地半径（格） |
| `hunterCount` | 0 | 猎人数，0 为自动 |

大厅和场地都在独立维度 `morphhide:reserve` 里，不会影响原来世界里的建筑。

## 开发与测试

需要 JDK 25。用本机 Homebrew 安装的 JDK 时，先设置：

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@25/libexec/openjdk.jdk/Contents/Home
```

```sh
./gradlew build
```

```sh
./gradlew runClientGameTest
```

```sh
./gradlew runClient
```

`runClientGameTest` 会启动真实客户端和内置服务器（测试时静音），加上几个模拟的局域网玩家，跑完整个流程，覆盖以下内容：

- 大厅、准备和开局
- 选动物、变身和移动速度
- 进食、诱饵和缩圈
- 战斗、打错惩罚、真动物补充
- 队友显示
- 断线重连和结算

截图保存在 `build/run/clientGameTest/screenshots/`。还没有在两台电脑之间做过真实联机测试。

### CI 与发布

- **Build**（`.github/workflows/build.yml`）：推送到 `main` 或提交 PR 时，会编译、跑单元测试、打包，jar 放在这次运行的 Artifacts 里。客户端游戏测试需要图形界面，CI 里不跑，发布前请在本机运行 `runClientGameTest`。
- **Release**（`.github/workflows/release.yml`）：在 GitHub 上发布一个 Release，标签写 `v` 加上 `gradle.properties` 里的 `mod_version`（比如 `v0.13.0`），CI 就会构建对应版本，把 `morph-hide-and-seek-<版本>.jar` 附到这个 Release 上。标签和版本号对不上时，构建会直接失败，不会附上错版本的 jar。

```sh
gh release create v0.13.0 --title "0.13.0" --notes "见 CHANGELOG.md"
```
