# 动物移动速度 · 0.4.3

参数核对自本项目依赖的 Minecraft 26.3 原版源码，未沿用旧版本的网上速度表。

| 动物 | MOVEMENT_SPEED 基础值 | 普通游走倍率 |
| --- | ---: | ---: |
| 绵羊 | 0.23 | 1.0 |
| 猪 | 0.25 | 1.0 |
| 牛 | 0.20 | 1.0 |
| 鸡 | 0.25 | 1.0 |
| 兔子 | 0.30 | 0.6 |
| 狐狸 | 0.30 | 1.0 |

基础值在运行时从 `DefaultAttributes` 读取，不在模组里硬编码六套基础速度。游走倍率来自各动物 `registerGoals` 中的 `WaterAvoidingRandomStrollGoal`；牛的属性来自 `AbstractCow.createAttributes`，其余来自各动物的 `createAttributes`。

这些数字不是方块/秒。原版 `MoveControl.tick` 将“属性 × 游走倍率”传给 `Mob.setSpeed`，后者同时设置速度和向前输入。因此地面移动的加速度含这两个因子的乘积。把猪的 0.25 直接写到玩家速度属性上，会让它远快于普通猪。

本次修改在 `Player.travel` 入口换算水平输入，使地面加速度对应原版动物的普通行走计算，同时抵消玩家输入的 0.98 缩放。空中和流体使用动物的向前输入倍率。客户端与服务端使用相同逻辑，不修改玩家永久速度属性或相机视野。动物形态拒绝玩家疾跑请求，避免疾跑属性加成和疾跑跳跃的额外水平冲量；猎人、未变身玩家不受影响。

范围为普通行走速度，不复制 AI 的随机停顿、惊慌逃跑倍率或兔子自动跳跃节奏；跳跃仍由玩家操作，地形摩擦和碰撞仍使用原版物理。

## 实测

`MovementScenario` 在测试存档创建平坦跑道，以真实客户端按住前进键测量位移。六种化身逐一与独立原版动物的水平行走物理对照（原版 `Mob.setSpeed` 与 `LivingEntity.travel`，无 AI 路径停顿）。另验证猪按疾跑键不会加速、疾跑跳跃无额外水平冲量、恢复人形后仍可正常疾跑。

运行：`./gradlew build runClientGameTest`。2026-11-03 完整通过，9 项原有单元测试、客户端流程、击杀淘汰流程、速度对照及残留实体清理回归均通过。日志见 [0.4.3 验证日志](testing/0.4.3/verification.log)。
